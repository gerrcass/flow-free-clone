# Vite + TypeScript + React for web v1

Chose a robust Vite + TypeScript + React scaffold over single-file vanilla JS per user request, accepting build-toolchain lock-in for type safety, component structure, and testability as the Pack and rules grow.

## Considered Options

- Single-file vanilla JS + Canvas (rejected: fastest but harder to grow and test)
- Vite + TypeScript + React (chosen)
